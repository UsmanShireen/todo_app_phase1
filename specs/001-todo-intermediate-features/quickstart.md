# Quickstart Guide: Todo Application Intermediate Features

## Running the Application

1. Ensure Python 3.13+ is installed on your system
2. Navigate to the project directory
3. Run the application with: `python src/main.py`
4. Follow the on-screen menu prompts

## New Intermediate Features

### Adding Tasks with Priority and Tags
1. Select option to add a task
2. Enter title and description
3. Select priority level (High, Medium, Low) - defaults to Medium
4. Add tags as comma-separated values (e.g., work, urgent, project)

### Searching Tasks
1. Select search option from main menu
2. Enter keyword to search in titles and descriptions
3. View filtered results containing the keyword

### Filtering Tasks
1. Select filter option from main menu
2. Choose filter criteria (status, priority, or tag)
3. View tasks matching the criteria

### Sorting Tasks
1. Select sort option from main menu
2. Choose sort criteria (priority, alphabetical, or due date)
3. View tasks arranged according to the criteria

### Updating Task Attributes
1. Select update task option
2. Choose the task to modify
3. Update priority level or tags as needed

## Example Workflow

1. Run `python src/main.py`
2. Add a task with priority "High" and tags "work,urgent"
3. Add multiple tasks with different priorities and tags
4. Use search to find tasks containing a keyword
5. Filter tasks by priority to see all "High" priority tasks
6. Sort tasks by priority to see them in priority order
7. Update a task's priority or tags as needed
8. Continue using all features as needed
9. Select exit option to quit the application
