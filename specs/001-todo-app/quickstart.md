# Quickstart Guide: Todo Application

## Running the Application

1. Ensure Python 3.13+ is installed on your system
2. Navigate to the project directory
3. Run the application with: `python main.py`
4. Follow the on-screen menu prompts

## Basic Usage

1. Start the application
2. Select options from the main menu by entering the corresponding number
3. Follow the prompts to add, view, update, or manage tasks
4. Use option 6 to exit the application

## Example Workflow

1. Run `python main.py`
2. Select "1" to add a new task
3. Enter a title and optional description
4. Select "2" to view all tasks
5. Continue using the menu to manage your tasks
6. Select "6" to exit the application
